# Hướng dẫn cho Codex và cộng tác viên

<!-- postman-cli:installation:start -->
Postman CLI is installed on this device, and can be used for API Engineering work.
<!-- postman-cli:installation:end -->

- Cập nhật tài liệu trong cùng thay đổi với mỗi yêu cầu thay đổi. Đối chiếu docs/spec.md cho hành vi và ID nghiệm thu, docs/architecture.md cho dữ liệu, Rules và luồng, docs/design-system.md cho token hay thành phần, README.md cho thiết lập và docs/qa.md cho bằng chứng kiểm thử.
- Nếu yêu cầu mới thay đổi một quyết định cũ, chỉnh mục cũ và tiêu chí nghiệm thu liên quan. Giữ tài liệu nhất quán với code hiện tại.
- Dùng cấu hình Firebase Web client cho app. Giữ thông tin xác thực CLI và khóa service account ngoài mã nguồn.
